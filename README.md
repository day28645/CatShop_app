🐱 CatShop App - E-Commerce Frontend Application
📌 Overview

CatShop App เป็นระบบ Frontend Web Application สำหรับร้านค้าออนไลน์ (E-Commerce)
พัฒนาด้วย React (JavaScript) และเชื่อมต่อกับ CatShop API (ASP.NET Core Web API)

รองรับการใช้งานตั้งแต่การเลือกสินค้า ไปจนถึงการสั่งซื้อสินค้าแบบครบวงจร (End-to-End)

👤 User Authentication
- สมัครสมาชิก (Register)
- เข้าสู่ระบบ (Login / Logout)
- ใช้ JWT Token จาก API

🛍️ Product Browsing
- แสดงรายการสินค้า
- ดูรายละเอียดสินค้า
- แสดงหมวดหมู่สินค้า

🧺 Shopping Cart
- เพิ่มสินค้าในตะกร้า
- ลบสินค้าออกจากตะกร้า
- คำนวณราคารวม

📦 Order System
- สร้างคำสั่งซื้อ
- แสดงรายการสินค้าในคำสั่งซื้อ
- ตรวจสอบสถานะคำสั่งซื้อ
